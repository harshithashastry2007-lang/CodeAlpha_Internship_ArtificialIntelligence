# 🤖 AI FAQ Chatbot

An intelligent FAQ Chatbot developed as part of the **CodeAlpha Artificial Intelligence Internship**.

The chatbot uses Natural Language Processing techniques to understand user queries and retrieve the most relevant answer from a predefined FAQ dataset.

## ✨ Features

- 💬 Interactive chatbot interface
- 🧠 NLP-based text preprocessing
- 🔎 Intelligent FAQ matching
- 📊 Similarity confidence score
- 🗑️ Clear chat functionality
- 💡 Suggested questions
- ⚡ Fast and user-friendly interface
- 🎨 Clean Streamlit UI

## 🧠 How It Works

The chatbot uses:

1. **Text Preprocessing** to clean user queries.
2. **TF-IDF Vectorization** to convert text into numerical vectors.
3. **Cosine Similarity** to compare the user's question with stored FAQs.
4. The FAQ with the highest similarity score is selected.
5. The corresponding answer is displayed to the user.

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Natural Language Processing (NLP)

## 🚀 How to Run

1. Clone the repository.

2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   python -m streamlit run app.py

4. Open the local URL displayed in the terminal.
