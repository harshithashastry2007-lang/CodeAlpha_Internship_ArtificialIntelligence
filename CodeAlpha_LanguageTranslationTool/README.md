# 🌐 AI Language Translation Tool

An AI-powered Language Translation Tool developed as part of the **CodeAlpha Artificial Intelligence Internship**.

The application allows users to translate text between multiple languages through a simple and interactive interface.

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔄 Swap source and target languages
- 🗑️ Clear input and output
- 📋 Copy translated text
- 🔊 Text-to-Speech for translated content
- ⚡ Fast and user-friendly interface
- 🎨 Clean Streamlit UI

## 🛠️ Technologies Used

- Python
- Streamlit
- Deep Translator
- Google Translate
- gTTS (Google Text-to-Speech)

## 🚀 How to Run

1. Clone this repository.

2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   python -m streamlit run app.py

4. Open the local URL displayed in the terminal.

## 📌 How It Works

1. Enter the text you want to translate.
2. Select the source language.
3. Select the target language.
4. Click **Translate**.
5. View the translated result.
6. Copy or listen to the translated text.
